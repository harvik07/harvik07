# 🚀 Things I've Been Building

### 📈 NITI-Lite — Regulatory Alpha in Indian Markets
Capstone research project: can regulatory announcements predict how Indian stocks move? An AI system reads regulatory events, reasons about their causal impact, and validates every signal before it counts. Research paper in progress.

```
Regulatory events ──▶ Causal LLM analysis ──▶ Deterministic validator ──▶ Alpha signal
```

### 🌍 Export Intelligence Platform
Full-stack agentic AI system for export trade intelligence: finds and scores buyers across target countries, tracks prices, and drafts research-backed outreach instead of generic cold emails.

`React` `FastAPI` `PostgreSQL` `Claude API`

```
Trade data ─▶ Buyer discovery ─▶ Scoring model ─▶ Price tracking ─▶ Targeted outreach
```

### 🧠 [Agentic AI Research System](https://github.com/harvik07/AGENTIC-AI-RESEARCH-FINAL)
A multi-agent system with planning, search and analysis agents that writes structured research reports on any topic, using Selenium, BeautifulSoup and REST APIs for scraping, plus a local-model fallback.

```
Topic ─▶ Planner ─▶ Search (Tavily · Wikipedia · arXiv) ─▶ Reader ─▶ Report
                        Gemini (cloud)  ⇄  Ollama (local fallback)
```

### 🩺 [MedScope AI](https://github.com/harvik07/MedScopeAI)
Upload a medical report PDF and get plain-language answers and audio explanations, plus disease prediction, chest X-ray pneumonia detection with a CNN, and Telegram medicine reminders.

### 👁️ [Customer Time-in-Store Tracking](https://github.com/harvik07/OpenCV_YOLO11_Customer_time_Store)
Computer vision with YOLO11 + OpenCV to detect customers and measure how long they spend in a store.

### 🏭 [Digital Twin for Intelligent Warehousing](https://github.com/harvik07/digital-twin)
Flask-based warehouse digital twin with a live 2D layout, dashboards, and ML-based demand forecasting.
